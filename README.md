# BMI Calculator GUI

A Python-based **BMI (Body Mass Index) Calculator GUI** developed using **Tkinter** as part of the **Oasis Infobyte Internship - Task 2**.

Developed by **Adithya Gajadi** *(Internship Pursuing Student)*

---

## Project Overview

The BMI Calculator GUI is a simple and interactive application that helps users calculate their **Body Mass Index (BMI)** using their weight and height.

The application also categorizes BMI into standard health categories such as:
- Underweight
- Normal Weight
- Overweight
- Obese

Additionally, the application stores BMI records and allows users to view previous calculation history.

---

## Features

✅ User-Friendly GUI using Tkinter  
✅ BMI Calculation System

## BMI Formula Used

BMI = Weight (kg) / Height² (m²)

---

## BMI Categories

| BMI Range | Category |
|------------|------------|
| Less than 18.5 | Underweight |
| 18.5 - 24.9 | Normal Weight |
| 25.0 - 29.9 | Overweight |
| 30 and above | Obese |
